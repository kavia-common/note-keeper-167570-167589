# Notes Backend (ASP.NET Core Minimal API, .NET 8)

- API Docs: visit /docs (Swagger UI powered by NSwag).
- Health: GET /
- Notes REST:
  - GET /api/notes
  - GET /api/notes/{id}
  - POST /api/notes
  - PUT /api/notes/{id}
  - DELETE /api/notes/{id}
